# Portfolio Examples — примеры работ

Готовые примеры аналитических шаблонов в Excel (демо-данные, без реальных данных
заказчиков). Показывают навыки работы с данными, формулами и Excel.

## Содержимое

| Файл | Что показывает |
|---|---|
| `unit-economics-demo.xlsx` | Юнит-экономика для маркетплейса: маржа по каждому SKU (цена − себестоимость − комиссия − логистика − эквайринг), сводка по дашборду, контроль расчёта |
| `osv-check-demo.xlsx` | Проверка оборотно-сальдовой ведомости из 1С: сбалансированность оборотов Дт/Кт, арифметика сальдо, контроль |

К каждому файлу приложен исходник сборки (`*.build.cjs`) — как он устроен.

## Как использовать

1. Скачайте нужный `.xlsx`.
2. Замените демо-данные на свои (лист с данными, всё пересчитается автоматически).
3. Настройте под свою задачу.

Шаблоны построены на формулах — редактируете входные данные, и итоги/дашборд
пересчитываются сами.

## Структура файла (пример)

- **Дашборд** — ключевые показатели одним взглядом
- **Данные / ОСВ** — исходные данные (демо)
- **Проверки** — контроль расчётов (статус OK/FAIL)

Без секретов и персональных данных — только демонстрационные цифры.
